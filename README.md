# Choosatron story catalog

Generated by `_tools/catalog_build.py` in cdam-ink-stories. **Do not edit anything
here**, blurbs included: every file is replaced on the next build. Change the story,
its `blurb.json` or `curation.json` in cdam-ink-stories and rebuild.

- `index.json` - the catalog, schema 1
- `blurbs/<lang>.json` - descriptions, keyed by work
- `s/<ifid>/<version>.cdam` - one compiled story per edition
- `index.html`, `w/<work>/`, `assets/` - the website, rendered from `_tools/site/`

Every story is © its author and is here for play on Choosatrons, with the author's
agreement. Translations appear only for works whose author has approved them; they
are machine translations unless an edition's `translation` says `human`.

The repository keeps no history: every build replaces `main` with one commit
(`catalog_build.py --commit`), which is then force-pushed. GitHub Pages serves the
tree as-is.
Design: choosatron-esp32-s3 `docs/story-catalog-spec.md`.
